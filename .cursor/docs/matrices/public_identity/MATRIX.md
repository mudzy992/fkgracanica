# Public Identity — Design Matrix

## Tokens
| Token | Light | Usage |
|-------|-------|-------|
| primary | #1e3a8a | CTA, links, hero |
| font-sans | Inter | body |
| font-display | Plus Jakarta Sans | h1–h3, logo |
| gradient-page-hero | subtle navy fade | page headers |
| glass-card | blur card | all cards |
| shadow-premium | elevation hover | cards, CTAs |

## Primitives
- `PageHeroHeader` — page top hero
- `PublicSection` — section title + Reveal
- `PremiumCard` — glass card
- `FormShell` — two-column form layout
- `EmptyState` — no results

## Pages (target)
All 20 public routes use primitives + motion + responsive `sm:px-6`.
