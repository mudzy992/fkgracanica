# Phase 2 — Public Parity

## Cilj

Dodati read-only mobilne ekrane za javne module koje web već ima, uz reuse postojećeg API-ja i minimalan broj novih shared komponenti.

## Moduli

- Galerija
- Tim / Klub / Igrač
- Liga / Match center / statistike
- Sponzori
- Trofeji
- Vremenska linija
- Hall of Fame
- Muzej
- Kontakt
- Newsletter
- Pretraga
- CMS stranice po slug-u

## Napomena

CRUD i builder radnje ne ulaze u ovu fazu. Fokus je browse/read experience, deep links i parity public sadržaja.
